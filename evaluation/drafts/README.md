FinanceBench open-source records. The original `evaluation/cases.json` is unchanged.

## Source-audited retrieval diagnostics

`source_audit.json` records candidate physical PDF pages and text hashes. All 39
current additions have exact normalized source-excerpt matches. This does not
verify the reference answers, calculations, completeness, or semantic uniqueness.
Known review items include Costco total assets and Microsoft COGS overlapping the
baseline, acquisition-answer completeness, and inventory-turnover denominator
ambiguity. Keep these in the diagnostic rather than selectively dropping failures.

Run the independent retrieval-only diagnostic in PowerShell:

```powershell
$env:STATEMENT_AWARE_RANKING = "1"
python scripts/run_audited_retrieval.py `
  --vector-store data/processed/local_sentence_transformers/vectors.sqlite3 `
  --output evaluation/results/expanded_retrieval_audit.json
```

This checks the draft hash and unchanged original cases, refuses ambiguous source
page matches, and saves progress after each query. It measures the complete
retrieved context (including neighbors), not just the first K returned chunks.
It separates original/addition/combined results and reports both any-page and
all-evidence-page recall. No answer accuracy or citation accuracy is claimed.
Generation evaluation remains blocked until source answers and grading rubrics
are reviewed. The new records are not an independently held-out test set.
